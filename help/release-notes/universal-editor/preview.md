# 범용 편집기 미리보기 릴리스 정보 {#preview}

다음은 범용 편집기 **미리보기 버전**&#x200B;에 대한 릴리스 정보입니다. 이러한 기능은 현재 범용 편집기의 **미리보기 환경**&#x200B;에서 사용할 수 있습니다. 이러한 기능은 2026년 5월 14일에 일반 출시될 예정입니다.

이 **미리 보기** 릴리스 노트는 편리하게도 제공되므로 유니버설 편집기에 대한 변경 사항이 예정되어 있는지 알고 [미리 보기 버전으로 전환하여 테스트할 수 있습니다.](/help/sites-cloud/authoring/universal-editor/navigation.md#user-properties)

>[!TIP]
>
>범용 편집기의 **현재 릴리스 정보**&#x200B;에 대해 알아보려면 [범용 편집기 릴리스 정보](/help/release-notes/universal-editor/current.md) 문서를 참조하십시오.

>[!NOTE]
>
>실제 릴리스의 콘텐츠와 릴리스 날짜는 변경될 수 있습니다.
