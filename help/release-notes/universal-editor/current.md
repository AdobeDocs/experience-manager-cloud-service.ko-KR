# Universal Editor 2026.05.14 릴리스 노트 {#release-notes}

유니버설 편집기의 2026년 5월 14일 릴리스에 대한 릴리스 정보입니다.

>[!TIP]
>
>릴리스하기 전에 **예정된** 범용 편집기 기능을 테스트하려면 [범용 편집기 미리보기 릴리스 정보](/help/release-notes/universal-editor/preview.md)를 참조하십시오.

## 새로운 기능 {#what-is-new}

* [속성 패널](/help/sites-cloud/authoring/universal-editor/navigation.md#properties-panel)이 기본적으로 열립니다.
* [확장 아이콘이 스펙트럼 2로 마이그레이션되었습니다.](https://developer.adobe.com/uix/docs/services/aem-universal-editor/api/header-menu/)

## 기타 개선 사항 {#other-improvements}

* 리치 텍스트 편집기에서 저장할 때 공백 및/또는 특수 문자가 있는 URL이 이제 제대로 백분율로 인코딩됩니다.
